# 识海核心（Core）

这里是《识海》数字生命的**核心知识入口**：用最短路径讲清「状态动力学决定何时说、为什么说，大模型只负责怎么说」这一主干，并索引到论文、仿真、代码与关键设计决策。

> 受 AstrBot 框架约束，可执行插件必须位于 `plugins/`，因此本目录承载**核心机制的文档与架构索引**，而非可运行代码。代码位置见文末映射表。

## 1. 核心思想：动机与语言解耦

普通机器人是「提示词 + 工具」：每轮由大模型直接决定一切。识海把**驱动力**从语言模型里剥离出来，交给一个独立、连续运行的状态动力学系统：

- 动力学内核（毫秒级、零 LLM）持续演化状态，决定「什么时候开口、为什么开口」；
- 大模型（DeepSeek）只在被触发时，负责「这句话具体怎么说」。

这样人格与情绪是连续、可积累的，而不是每轮重新扮演。

## 2. 状态向量 z(t)

`z(t) = [e, a, θ, ψ, u, g]`

| 分量 | 含义 |
|---|---|
| `e` | 六维情绪场（happy/sad/angry/fear/love/surprise） |
| `a` | 神经图谱激活 |
| `θ` | 慢演化参数（含反馈自适应，饱和上限 3.5） |
| `ψ` | 大五人格 |
| `u` | 念头强度（累积达阈值 FIRE_THRESHOLD=2.10 后释放） |
| `g` | 内生目标 |

五组方程耦合（情绪场 ODE、图谱扩散、Hebbian 边权、念头累积、自适应演化），构成四个耦合回路。

## 3. 分层与数据流

```
QQ 好友/群
   │  SnowLuma（QQ 运行时，OneBot 11，反向 WS :6199）
   ▼
AstrBot 框架
   ├─ 动力学内核：z(t) 连续演化 → 输出结构化意图包 I_t
   ├─ 记忆层：神经图谱（零 LLM）+ 事实/事件分桶 + 逐字归档
   ├─ 守护层：四条不变量，只读 z(t) 做一致性审计
   ▼
大模型（DeepSeek）：依据意图包生成语言，工具调用闭环
   ▼
回复经 QQ 发出；实际出口文本回写短上下文与逐字库
```

意图包 `I_t = {G_active, E_t, M*_t, P_t, intent-type}`，连同简短固定指令是 LLM 仅有的动力学侧输入。

## 4. 记忆的两层

- **神经图谱层（零 LLM）**：关键词/事件/情绪/高光节点入图，扩散激活召回 top-k；衰减率按节点类型与情绪调制，凌晨梦境固化重放与修剪。
- **记忆库层（`memory_v2`）**：事实与事件按艾宾浩斯保持率 `R=e^{-Δt/S}` 衰减，稳定度 `S` 由重要度、情绪峰值、复习次数共同决定；**逐字归档（transcript）**另存原话，窗口外也能按需取回，不常驻前缀、不影响缓存。
