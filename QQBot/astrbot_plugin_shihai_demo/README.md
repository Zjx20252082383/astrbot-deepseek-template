# 识海 QQ 对话 Demo

版本：`0.1.1`。

在 AstrBot 已配置的 QQ 官方机器人与对话模型上，接入识海心智状态、人格表达参数和图谱记忆。插件在模型请求前更新状态并追加意图包，复用 AstrBot 的模型配置。

## 使用

- 验证环境：AstrBot 4.29.4、Python 3.12、jieba 0.42.1。
- QQ 平台实例 ID 需与 `main.py` 的 `PLATFORM_ID` 一致，当前为 `qqbot_deepseek`。
- 普通文字消息更新状态并参与记忆；发送 `/心境` 查看情绪、人格参数、图谱数量及注入标记。
- 状态按“平台会话 + 发送者”隔离，保存到 AstrBot 的插件数据目录。
- `/new` 新建模型会话，不清除插件记忆；“本次启动后已注入”标记在重载或重启后重新开始记录。
- 主动外发关闭，当前交付范围是被动文字对话。

## 交流方式

可使用 AstrBot 配置中的轻量风格提示词，约定自然交流、围绕话题和避免套话。具体句长、语气与共情程度由当前人格参数生成，情绪与动机依据本轮意图包，避免额外固定性格和心情。

## 验证范围

13 项本地单元测试及真实 AstrBot 加载测试通过。真实 QQ 已观察到 `0.1.1` 热重载成功，以及明确更正为草莓、执行 `/new` 后正确召回当前偏好的样例；这些结果不代表所有记忆场景都已验证。

完整部署脚本、测试、人工验收清单和记录位于源码仓库的 `QQBot/` 目录。更新内容见本目录 `CHANGELOG.md`。
