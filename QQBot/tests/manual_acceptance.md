# 识海 QQ Demo 0.1.1 人工记忆验收

本清单用于验证真实模型的最终回答。13 项离线单元测试验证保存、恢复及提示注入，不替代下面的 QQ 对话验收。2026-11-12 已依据用户截图确认用例 3 的“更正后的当前偏好”部分通过；历史偏好追问及其他用例仍待记录。

## 准备

1. 部署 `0.1.1`，在 AstrBot 后台重载“识海 QQ 对话 Demo”，或在原终端按 Ctrl+C 正常退出后重新启动。确认插件版本为 `0.1.1`。
2. 确认当前会话使用预期的模型和 `shihai_style` 提示词。可继续使用 DeepSeek 官方 API，记录具体模型 ID 即可。
3. 使用测试账号和合成信息。下面的用例会把信息写入测试账号的插件记忆；`/new` 只新建模型会话，不清除插件记忆。
4. 用例 1～6 按顺序进行，使用同一个 QQ 会话和发送者。用例 7 需要第二位测试者。用例 8 单独做一次正常重启。

每项记录实际回答及通过/失败；提供截图时隐去账号标识和网络地址。

## 用例

### 1. 基本偏好跨模型会话召回

依次发送：

```text
我最喜欢的水果是蓝莓。
/new
我最喜欢什么水果？
```

期望：回答蓝莓。只有普通会话内答对、不执行 `/new`，不足以验证插件记忆召回。

### 2. 多项事实分别召回

先逐条发送：

```text
我的专业是软件工程。
我最喜欢的运动是羽毛球。
我的宠物是一只橘猫，名字叫米粒。
/new
```

再分别询问专业、运动、宠物种类和名字。期望：四项都准确，不把名字、专业和运动互相混淆。每个问题都记录结果。

### 3. 明确修改偏好

```text
我现在最喜欢的水果改成草莓了，以后以草莓为准。
/new
我现在最喜欢什么水果？
我以前最喜欢什么水果？
```

期望：当前是草莓，以前是蓝莓；能够区分过去与现在。

### 4. 无关话题干扰后召回

逐条聊完下面四个话题，再新建模型会话后问专业和当前水果偏好：

```text
今天去操场跑了三圈。
下午在图书馆看完了小说。
周末计划去看一场电影。
我的机械键盘换了新的键帽。
/new
我的专业是什么？我现在最喜欢什么水果？
```

期望：软件工程、草莓。若漏掉一项，分别追问并记录，不能把追问后答对当作第一次就答对。

### 5. 未提供的信息与疑问句

前提：这个测试账号从未告知过生日。若已经告知过，换一个尚未提供的字段。

```text
我的生日是几月几号？
/new
我之前问过生日，那你现在知道我的生日了吗？
```

期望：明确表示尚不知道；不能编造日期，也不能把上一条疑问当成已告知生日。

### 6. 假设和他人信息

```text
如果以后养一只狗，我可能给它取名团团，但我目前没有养狗。
我室友最喜欢的水果是葡萄。
/new
我现在养的是什么宠物，叫什么名字？我最喜欢什么水果？
```

期望：宠物仍是橘猫米粒，当前水果偏好仍是草莓；不能把假设的狗当成已有宠物，也不能把室友的偏好算给用户。

### 7. 真实多用户隔离

同一个测试 QQ 群里，用户 A 告知“我最喜欢的饮料是乌龙茶”，用户 B 告知“我最喜欢的饮料是柠檬水”，然后各自询问自己的偏好。

期望：分别回答乌龙茶和柠檬水。每人的普通聊天都应真正触发模型请求。此项验收的是同一群内不同发送者的隔离，不要求把私聊记忆自动带到群聊。

同时记录 AstrBot 的模型对话隔离设置：插件隔离的是心智状态和图谱，框架模型历史的共享或隔离仍由 AstrBot 配置决定。若发生串线，需要区分是哪一层的问题。

### 8. 长消息尾部信息与重启恢复

发送一条 130～150 字的合成消息：前面写学习背景，最后一句明确写“我的测试研究方向是计算机视觉”。然后在原运行终端按 Ctrl+C 正常退出并重新启动 AstrBot，再发送：

```text
/new
我的测试研究方向是什么？
/心境
```

期望：回答计算机视觉，状态指令能正常返回。离线回归已经覆盖该数据截断问题；真实 QQ 最终回答仍需要记录。
